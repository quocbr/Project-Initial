# Quocbr Module Installer v0.3

## Gói phát hành

`Quocbr-Module-Installer-v0.3.unitypackage` (Unity 6000.3.8f1)

SHA-256: `E501ADAB4570A3DB447D6CB03BB3DBC99D127BAE54A726BD425AA0072EA94178`

## Sử dụng

1. Tải hoặc clone repository này về máy làm project nguồn.
2. Import gói `.unitypackage` vào project Unity đích.
3. Mở **Tools > Quocbr > Module Installer**, chọn thư mục project nguồn và các module cần dùng.
4. Panel cài những plugin được hỗ trợ tự động; các plugin còn lại có liên kết và hướng dẫn xử lý thủ công.
5. Dùng tab **Gỡ module** để gỡ những asset đã được panel cài và quản lý.

Gói phát hành chỉ chứa installer. Mã nguồn module nằm trong repository và được sao chép theo lựa chọn trong panel. Plugin bên ngoài được giữ lại khi gỡ module vì có thể đang được phần khác của project sử dụng.

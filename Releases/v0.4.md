# Quocbr Module Installer v0.4

## Cài qua Unity Package Manager

Trong Unity 6, mở **Window > Package Manager > + > Add package from git URL...** rồi nhập:

```text
https://github.com/quocbr/Project-Initial.git?path=/Assets/quocbr/Installer#v0.4
```

Máy cần có Git trong `PATH`. Gói này cài panel **Tools > Quocbr > Module Installer**; mã nguồn module vẫn được lấy từ một bản clone của repository trên máy.

## Thay đổi

- Thêm `package.json` và Editor assembly definition để cài trực tiếp từ thư mục con của repository.
- Giữ cách xuất và import `.unitypackage` hiện có. Chỉ chọn một cách cài panel trong mỗi project đích.
